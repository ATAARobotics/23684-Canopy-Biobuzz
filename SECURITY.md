# Security Policy

If you discover a security vulnerability in this repository, please report it
privately to **techtitans23684@gmail.com** rather than opening a public issue.

Please include:

- A clear description of the vulnerability
- Steps to reproduce, or a proof-of-concept if possible
- The affected component(s) and version/commit

We will acknowledge reports within a reasonable timeframe and work with you to
resolve the issue before any public disclosure.

## Supported Versions

Only the `main` branch receives security fixes. Older commits are not
maintained.
